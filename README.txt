IGOVPH / GWT
The page loads the official iGovPhil Government Website Template Foundation CSS from the iGovPhil GitHub CDN, then applies the local Juban CSS/JS presentation layer.

The Philippine time display uses the visitor's device clock, formatted in the Asia/Manila time zone (UTC+08:00). It renders immediately and refreshes every second without the external GWT time widget. It is not a live-synchronized PAGASA feed.
